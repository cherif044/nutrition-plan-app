# Dead Code Detection Rules

When detecting unused code:

1. Search all source files.
2. Check imports and exports.
3. Check route registration.
4. Check frontend routing.
5. Check config references.
6. Check dynamic imports.
7. Check string-based references.
8. Check framework conventions.
9. Check tests only separately from runtime usage.
10. Mark anything uncertain as uncertain.

Do not delete anything.

For each unused candidate, give confidence:

- High confidence: no references found anywhere and no framework/dynamic usage likely.
- Medium confidence: no direct references, but indirect usage is possible.
- Low confidence: looks suspicious, but usage cannot be ruled out.

Also give deletion risk:

- Low risk: safe to delete after tests pass.
- Medium risk: delete only after manual verification.
- High risk: do not delete without deeper investigation.
